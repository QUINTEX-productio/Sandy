# Sandy — ver Alpha (`v0.1.0-alpha`)

First public Alpha release of **Sandy** for **Windows** and **Android**!

## Downloads
- **Windows (64-bit Installer):** `Sandy-Setup-Alpha-x64.exe`
- **Android (Universal APK):** `Sandy-Alpha.apk`

## Highlights
- **First-Launch Experience:** Splash screen, Firebase Email + Google Sign-In, 3-Step Personalization Survey, and 7-Step Interactive Tutorial.
- **Scroll-to-Circle Navigation:** Left vertical sidebar rail with animated glowing circle indicator + Home Menu + Top-Right Profile/Sign Out dropdown.
- **Devices Manager:** Bluetooth pairing, red **Add Device** button, **How to Add Device** guide, sideways beveled list, and top-left `⋮` menu (**Preferences**, **Rename**, **Delete**).
- **Minimal Live Interface:** Clean Camera + **GOOD / BAD** live posture reading + centered circle start button + **Choose device** Bluetooth dropdown, with Colab YOLOv5 auto-wake, 740 Hz alerts, and auto-recording in the backend.
- **Sandy AI Chatbot (`Qwen3.6-35B`):** Auto-wakes Colab GPU and enforces strict posture/ergonomics-only responses.
- **Reports & Recorded Media:** Daily / Weekly / Monthly / Yearly boxes, missing-day notice + **Day-1 Baseline comparison**, **YOLOv5 → Qwen3.6 → Report** summaries, and recorded images/videos gallery.
- **Settings:** App version (`ver Alpha`), 4 Cyberpunk color themes, audio/recording toggles, and tutorial replay.

## Install Notes
- **Windows:** If SmartScreen prompts on an unsigned Alpha installer, click **More info → Run anyway**.
- **Android:** Enable **Install unknown apps** when opening `Sandy-Alpha.apk`.
- **macOS / iOS:** Use the web app directly at https://quintex-productio.github.io/sandy.io/ — no install needed!
